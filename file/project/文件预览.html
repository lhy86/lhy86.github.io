LHY文件预览

拖入、选择文件，或粘贴公开下载链接。系统会根据文件签名、MIME 与内部结构自动识别格式；本地文件不会上传到服务器。

直开格式：LHY文件预览.html?file=<encodeURIComponent(下载地址)>&name=可选文件名.pdf

PDF / 文本

图片

JPEG、PNG、GIF、WebP、AVIF、SVG、BMP、ICO、TIFF（依浏览器解码能力）。

文件与兼容性信息

    

      
服务
LHY文件预览
支持范围
Office、PDF、图片、音频、视频、文本代码与 ZIP
处理方式
本地文件在浏览器中解析，不上传

      

        兼容性说明

        LHY文件预览优先保证安全、可读性、导航与常见版式。Office 的特殊字体、OLE、ActiveX、复杂域和少数高级效果可能与桌面软件有差异；宏和脚本不会执行。音视频能否播放取决于浏览器、系统与文件内部编解码器。PDF 由 PDF.js 渲染，图片优先使用浏览器原生解码。
      

      
使用的浏览器端组件：docx-preview、SheetJS Community Edition、pptx-renderer、PDF.js 与 JSZip。正式部署建议固定版本并本地托管依赖；跨域下载链接可配合附带的可选 Python 服务。
